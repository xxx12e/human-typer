# 隐私政策

最后更新：2026-10-26

人类打字模拟器（以下简称「本扩展」）在你的浏览器本地运行。本扩展不收集、不上传、不共享任何数据。

## 本扩展处理哪些数据

| 数据 | 存放位置 | 用途 | 是否离开本机 |
| --- | --- | --- | --- |
| 你填写在侧边栏的文字 | 扩展本地存储 | 关闭面板后继续编辑 | 否 |
| 节奏参数与模式 | 扩展本地存储 | 记住你的设置 | 否 |
| Google 文档续打记录（文档地址、上次发送的文字、已发送字数） | 扩展本地存储 | 下次对同一文档续打时使用 | 否 |
| 输入框光标前后的文本 | 内存 | 点击「开始」时判断是否已输入过开头 | 否 |

本扩展不读取网页整体内容，不读取浏览器历史、书签、Cookie 或密码，不记录键盘输入，不包含任何分析或广告代码。

## 网络访问

本扩展不发出任何网络请求，没有服务器端组件，也没有第三方依赖。所有逻辑都由随扩展一同分发的本地 JavaScript 文件执行，不加载远程代码。

## 权限说明

- `activeTab`、`scripting`：在你点击「选择网页输入框」后，把输入引擎注入你选中的标签页及其 iframe。
- `sidePanel`：使用浏览器原生侧边栏作为控制面板。
- `<all_urls>`：允许在任意网站与跨域 iframe 中定位你点击的输入框。
- `debugger`：只在向你选中的 Google 文档输入时连接，用于逐字发送按键；任务结束、切换标签页或关闭页面时自动断开。普通网页输入不会使用该权限。

## 数据删除

清空侧边栏文本框会清除保存的文字草稿；在扩展详情中移除本扩展会删除全部本地数据。本扩展没有远端数据，因此不存在远端删除流程。
