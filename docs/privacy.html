人类打字模拟器 · 隐私政策

最后更新：2026-10-26

本扩展在你的浏览器本地运行，不收集、不上传、不共享任何数据。

处理哪些数据

数据存放位置用途是否离开本机
侧边栏填写的文字扩展本地存储关闭面板后继续编辑否
节奏参数与模式扩展本地存储记住设置否
Google 文档续打记录（文档地址、上次发送的文字、已发送字数）扩展本地存储下次对同一文档续打否
输入框光标前后的文本内存点击开始时判断是否已输入过开头否

本扩展不读取网页整体内容，不读取浏览历史、书签、Cookie 或密码，不记录键盘输入，不包含分析或广告代码。

网络访问

本扩展不发出任何网络请求，没有服务器端组件，也没有第三方依赖。所有逻辑都由随扩展一同分发的本地 JavaScript 执行，不加载远程代码。

权限说明

  • activeTab、scripting：用户点击「选择网页输入框」后，把输入引擎注入所选标签页及其 iframe。
  • sidePanel：使用浏览器原生侧边栏作为控制面板。
  • <all_urls>：允许在任意网站与跨域 iframe 中定位用户点击的输入框。
  • debugger（可选）：仅在用户主动启用 Google 文档模式时申请，用于向文档逐字发送按键；任务结束、切换标签页或关闭页面时自动断开。

数据删除

清空侧边栏文本框会清除保存的文字草稿；移除本扩展会删除全部本地数据。本扩展没有远端数据。

变更与联系

策略如有变更会更新本页面并随版本发布。联系方式：本项目的 GitHub Issues。
