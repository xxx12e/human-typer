# 人类打字模拟器

在网页输入框里按设定节奏逐字输入文字的浏览器扩展（Edge / Chrome，Manifest V3）。

侧边栏控制面板，两种节奏可选：固定间隔逐字输入，或按句子构思、成段输出、随手回改的「边想边打」。支持普通输入框、iframe 富文本编辑器和 Google 文档。

## 功能

**两种节奏**

| 模式 | 说明 |
| --- | --- |
| 常规节奏 | 在设定的最短～最长间隔内逐字随机输入，可叠加标点停顿、节奏波动、单字错字纠正和随机思考停顿。内置慢速仔细、日常输入、熟练快打三组参数。 |
| 边想边打 | 先把文字按段落、句子、分句、词语切成结构，再规划成一串步骤：在分句和句末停下构思，成段快速输出，走到词或分句边界时回删几个字重写，打错了也可能过几个字才发现。 |

边想边打的参数全部是滑动条，拖动时每条下方实时显示该参数在当前文字上产生的次数与耗时：

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 书写速度 | 30～200 毫秒/字 | 成句书写时字与字的基准间隔 |
| 构思强度 | 0.4～2 倍 | 缩放所有构思停顿 |
| 回改频率 | 0～25% | 走到词或分句边界时回删重写的概率 |
| 单次回改上限 | 1～12 字 | 一次最多回删几个字 |
| 错字概率 | 0～10% | 打出邻近键位或混淆字的概率 |
| 延迟发现概率 | 0～15% | 打错后继续打几个字才一次退格重打的概率 |
| 走神长停顿概率 | 0～15% | 句末或段落后额外停 6～15 秒的概率 |
| 总时长预算 | 10 秒～120 分钟 | 让整段文字大致按指定时长打完 |

开启预算后只缩放构思类停顿，书写速度、回改次数和错字序列都不变。缩放范围限制在 0.15～8 倍，达不到目标时面板会说明是文字太短还是书写本身超时。

**进度按时间显示**

按钮正下方的进度条读数是 `38.20% · 剩余 2 分 13.45 秒`，百分比保留两位小数，按距离结尾的时间推进。边想边打用的是计划里真实的等待时间，构思停顿期间也会持续减少；常规模式按剩余字数估算。

**续打检测**

点击开始前会检查目标里已有的内容。如果光标前的内容正好是待输入文字的开头，面板会弹出提示，可以「从检测到的位置继续」或「从头输入」。要输入的文字如果已经整段存在于目标中，会提示不必重复。Google 文档正文不可读取，这里改用扩展自己记录的发送进度。

**Google 文档**

文档模式通过浏览器调试接口逐字发送真实按键事件：英文字母、数字、标点走 `keydown`/`keyup`（含 Shift 组合），中文等需要输入法提交的字符走输入法提交通道。每个按键之间按计划等待，文档收到的是一个一个键，不是整段插入。

调试器权限是可选权限，只有在你主动为文档模式点击启用时才会申请；普通网页输入不需要它。

**字符清洗**

输入前统一 NFC，制表符与 Unicode 空格转成普通空格，零宽字符、BOM、方向控制符、控制字符、私用字符、未配对代理项、表情和符号类字符会被删除，只保留字母、数字、可见标点、ASCII 空格和换行。清洗结果会回写到侧边栏文本框，方便开始前检查。

## 界面语言 / Interface language

侧边栏标题右边有一个语言按钮，点一下就在中文与英文之间切换，不用重启浏览器；选择保存在本地，下次打开保持不变。首次打开时跟随浏览器语言：`zh-*` 显示中文，其余显示英文。

面板文案、滑动条读数、进度、状态消息和 Google 文档模式的状态都会一起切换，正在运行的任务也会用新语言继续显示。

扩展名称与简介通过 `_locales` 本地化，扩展管理页与商店列表跟随浏览器语言。

The side panel has a language button next to the title. One click switches between Chinese and English without a restart, and the choice is remembered. The first launch follows the browser locale (`zh-*` uses Chinese, everything else uses English). Panel text, slider readouts, progress, status messages and Google Docs mode all switch together.

## 安装

从源码加载：

1. 下载本仓库（或 Release 中的 zip 并解压）。
2. Edge 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择包含 `manifest.json` 的目录。
4. 点击浏览器工具栏的扩展图标，侧边栏打开即用。

## 使用

1. 在侧边栏填写要输入的文字，选择模式和参数。
2. 点击「① 选择网页输入框」，再点击网页上要输入的位置。需要 30 秒内完成，按 Esc 取消。
3. 点击「② 开始」。进度条和状态文字会显示当前阶段。
4. 过程中按 Esc、手动按键、点击其他位置或切换输入框都会停止。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 取得当前标签页上下文 |
| `scripting` | 向用户选择的标签页和 iframe 注入输入引擎 |
| `sidePanel` | 使用浏览器原生侧边栏作为控制面板 |
| `host_permissions: <all_urls>` | 允许在任意网站及跨域 iframe 中寻找用户点击的输入框 |
| `optional_permissions: debugger` | 仅 Google 文档模式使用，启用时单独申请 |

## 隐私

所有代码在本地运行，没有服务器、没有第三方依赖、没有遥测，也不会把输入的文字上传到任何地方。

扩展不读取整页内容：普通输入框只在点击「选择网页输入框」后接触用户选中的元素；续打检测只比较光标前后的文本；Google 文档模式不读取文档正文，只按用户选择的输入位置发送按键。文字草稿和节奏设置保存在侧边栏自己的本地存储里，清空文本框或删除扩展即可清除。

## 兼容与限制

- 支持 `textarea`、`text/search/url/tel` 类型的 `input`、`contenteditable` 富文本正文，以及主页面与跨域 iframe 中的同类元素。
- 不支持 HTML `<canvas>` 绘图表面、PDF 只读页、密码框和非文本输入类型；Word 网页版等自绘图层编辑器可能需要单独适配。
- 中文字符不模拟拼音串与候选词窗口，扩展也不模拟鼠标移动和光标移动键。
- 网页可以修改写入的内容或拒绝输入事件；检测到网页改变了文字、光标或目标被移除时会立即停止。
- 浏览器设置页、扩展商店等受保护页面无法注入脚本；`file://` 页面需要在扩展详情中开启「允许访问文件 URL」。
- 扩展通过浏览器事件输入，不是物理键盘硬件信号。

## 开发

```bash
node tests/thinking.test.cjs   # 节奏规划器
node tests/typist.test.cjs     # 输入引擎与续打检测
node tests/sanitize.test.cjs   # 字符清洗
node tests/engine-reload.test.cjs
npm run pack                   # 生成 dist/ 下的 zip
```

浏览器端到端测试需要本机 Playwright 与 Edge，脚本不在仓库内提供。

文件构成：

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 清单、权限、侧边栏入口与图标 |
| `_locales/` | 扩展名称与简介的中英文消息 |
| `background.js` | 打开侧边栏；加载文案表、清洗器、规划器与文档输入器 |
| `popup.html` / `popup.js` | 侧边栏界面、参数、预览、进度、状态与语言切换 |
| `i18n.js` | 中英文文案表与翻译函数，面板与三处执行上下文共用 |
| `sanitize.js` | 字符清洗 |
| `thinking.js` | 边想边打节奏规划器（纯函数，无 DOM、无扩展 API） |
| `typist.js` | 普通输入框与富文本输入引擎 |
| `docs-target.js` | Google 文档正文选择与按键登记 |
| `docs-runner.js` | Google 文档调试连接与逐字按键发送 |
